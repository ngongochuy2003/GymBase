# Applications

- `mobile/`: Expo + React Native + TypeScript, Expo Router; V1.
- `api/`: ASP.NET Core 10, modular monolith theo BL / DL (một host `GymBase.API`), MySQL 8.4; V1.
- `web/`: Next.js; chỉ tạo khi bắt đầu task Web, dự kiến V2.

Mobile đã có Expo app và demo; API vẫn là hướng dẫn, chưa có .NET project.
Phát triển từng ứng dụng trực tiếp tại đường dẫn tương ứng; không tạo thêm
`GymBase/`, `gymbase-mobile/` hoặc repository Git lồng bên trong.
