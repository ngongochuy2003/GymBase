# Applications

- `mobile/`: Expo + React Native + TypeScript, Expo Router; V1.
- `api/`: ASP.NET Core 9 modular monolith, EF Core + MySQL; V1.
- `web/`: Next.js; chỉ tạo khi bắt đầu task Web, dự kiến V2.

Hiện tại mobile và api chỉ chứa hướng dẫn vị trí triển khai, chưa phải app chạy được.
Khởi tạo từng ứng dụng trực tiếp tại đường dẫn tương ứng; không tạo thêm
`GymBase/`, `gymbase-mobile/` hoặc repository Git lồng bên trong.
